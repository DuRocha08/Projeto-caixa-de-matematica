Caixa de Matemática

Uma aplicação web interativa e lúdica desenvolvida para auxiliar professores a organizar, guardar e compartilhar recursos pedagógicos para o ensino da matemática.

Objetivo do Projeto
O objetivo da Caixa de Matemática é centralizar ideias e materiais escolares, funcionando como um acervo digital. Os educadores podem cadastrar materiais manipuláveis, jogos, dicas de literatura, recursos digitais e criar propostas de atividades completas que ficam salvas na nuvem para toda a comunidade escolar acessar.

Funcionalidades
Separação por Gavetas: Organização intuitiva por categorias (Jogos, Literatura, Materiais Manipuláveis, Recursos Digitais, etc.).
Cadastro de Recursos: Formulários detalhados para inserir o conceito matemático, público-alvo e uso pedagógico.
Criação de Atividades: Espaço para planejar o desenvolvimento, a mediação e a avaliação de uma atividade usando os recursos da caixa.
Integração na Nuvem: Banco de dados que permite visualizar todos os recursos e atividades cadastrados em tempo real.
Interface Lúdica: Design responsivo, colorido e amigável (estilo aplicativo educativo).

Tecnologias Utilizadas
Frontend: HTML5, CSS3 (com tipografia do Google Fonts) e Vanilla JavaScript.
Backend: API (Node.js) para comunicação com o banco de dados.
Banco de Dados: MySQL para armazenamento persistente na nuvem.

Telas do Projeto
Página Inicial: Boas-vindas e entrada no sistema.
Menu de Gavetas: Navegação principal para escolher onde guardar a ideia.
Formulários: Preenchimento dos dados do recurso ou da atividade.
Murais (Listagens): Visualização em formato de cards de tudo o que já foi cadastrado no banco de dados.
